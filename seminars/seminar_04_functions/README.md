## Блок 1: Функции: def, параметры, return (10 мин)

### Зачем нужны функции

Посмотрите на знакомый код: он считает цену билета в трёх местах программы.

```python
if age < 7:
    price = 0
elif age < 18:
    price = 250
else:
    price = 450
```

Если такой фрагмент повторяется, с ним возникают три проблемы: его приходится
копировать, при изменении цен править нужно во всех копиях, а читающий код человек
каждый раз заново разбирается, что эти строки вычисляют.

**Функция** решает все три: это блок кода, которому дали имя. Один раз описали —
дальше вызываем по имени столько раз, сколько нужно:

```python
price = ticket_price(age)
```

Функции — это способ разбить программу на понятные части, каждая из которых делает
что-то одно и имеет говорящее имя.

### Определение и вызов

```python
def greet():
    print("Здравствуйте!")


greet()  # вызов: без него тело функции не выполнится
greet()  # вызывать можно сколько угодно раз
```

Разбор синтаксиса: `def` — инструкция определения функции, дальше имя, круглые скобки
и двоеточие. Тело пишется с отступом — как у `if` и `for`.

> Определение функции не выполняет её код. Python лишь запоминает:
> «теперь есть функция с таким именем».

### Параметры

Чтобы функция работала с разными данными, в скобках указывают **параметры**:

```python
def greet_user(name):
    print(f"Здравствуйте, {name}!")


greet_user("Анна")
greet_user("Иван")
```

- **Параметр** — имя в определении функции (`name`)
- **Аргумент** — конкретное значение при вызове (`"Анна"`)

Параметров может быть несколько — тогда при вызове важен их порядок:

```python
def print_student(name, group):
    print(f"{name} из группы {group}")


print_student("Анна", "Б01-123")
```

### return — вернуть результат

`print()` показывает значение на экране, а `return` **отдаёт** его обратно в программу —
чтобы сохранить в переменную и использовать дальше:

```python
def rectangle_area(width, height):
    return width * height


area = rectangle_area(7, 4)
print(area * 2)  # с результатом можно работать дальше
```

| Функция | Что делает | Результат вызова |
|---------|------------|------------------|
| `print(width * height)` | печатает на экран | `None` |
| `return width * height` | возвращает значение | число, его можно сохранить |

Две важные особенности:

- функция без `return` возвращает `None` — специальное значение «ничего»;
- `return` немедленно завершает работу функции, строки после него не выполняются.

### Докстринг и pass

Первая строка тела в тройных кавычках — **докстринг**, описание функции:

```python
def celsius_to_fahrenheit(celsius):
    """Перевести температуру из градусов Цельсия в градусы Фаренгейта."""
    return celsius * 9 / 5 + 32
```

Пустое тело Python не разрешает. Если функция ещё не написана, ставят заглушку `pass`:

```python
def send_email(address):
    pass
```

## Блок 2: Аргументы: по умолчанию и именованные (10 мин)

### Позиционные аргументы

По умолчанию аргументы распределяются по параметрам **в порядке записи**:

```python
print_student("Анна", "Б01-123")  # name = "Анна", group = "Б01-123"
print_student("Б01-123", "Анна")  # значения перепутаны местами
```

Python не замечает такой ошибки: для него это просто две строки. А вот неверное
**количество** аргументов он заметит сразу:

```
TypeError: print_student() missing 1 required positional argument: 'group'
```

### Именованные аргументы

При вызове можно явно указать, какому параметру какое значение передаётся. Тогда
порядок не важен, а сам вызов читается понятнее:

```python
print_student(name="Анна", group="Б01-123")
print_student(group="Б01-123", name="Анна")  # тот же результат
```

Это особенно полезно, когда аргументов много или когда по значению не догадаться,
что оно означает: сравните `ticket_price(20, True)` и `ticket_price(20, is_student=True)`.

### Значения по умолчанию

Параметру можно задать значение, которое используется, если аргумент не передали:

```python
def greet(name, greeting="Здравствуйте"):
    print(f"{greeting}, {name}!")


greet("Анна")  # Здравствуйте, Анна!
greet("Иван", "Привет")  # Привет, Иван!
```

Так одна функция покрывает и типичный случай, и особый.

> **Правило порядка:** параметры со значением по умолчанию идут **после** обычных.
> Иначе Python не поймёт, какому параметру относится переданное значение,
> и сообщит о `SyntaxError`.

> **Подробнее:** см. файл [`examples/02_arguments.py`](examples/02_arguments.py)

## Блок 3: Области видимости и возврат нескольких значений (10 мин)

### Локальные переменные

Переменная, созданная внутри функции, существует только во время её работы:

```python
def calculate_total(price, count):
    total = price * count  # локальная переменная
    return total


print(calculate_total(100, 3))
print(total)  # NameError: name 'total' is not defined
```

Параметры функции — тоже локальные переменные. Это удобно: внутри функции можно брать
любые имена, не боясь задеть переменные остальной программы.

### Глобальные переменные

Переменные, созданные вне функций, называются глобальными. Внутри функции их **можно
читать**:

```python
TAX_RATE = 0.2


def price_with_tax(price):
    return price * (1 + TAX_RATE)
```

А вот присваивание внутри функции глобальную переменную **не меняет** — создаётся новая
локальная переменная с тем же именем:

```python
counter = 0


def try_to_change():
    counter = 10  # новая локальная переменная
    print(counter)  # 10


try_to_change()
print(counter)  # 0 — глобальная не изменилась
```

Правильный способ изменить значение — вернуть его из функции и присвоить:

```python
counter = increased(counter)
```

> Инструкция `global` разрешает менять глобальную переменную изнутри функции, но
> пользоваться ей не стоит: функцию, которая незаметно меняет что-то снаружи,
> тяжело читать и отлаживать.

### Возврат нескольких значений

После `return` можно перечислить несколько значений через запятую — функция вернёт
кортеж (семинар 3), который обычно сразу распаковывают:

```python
def min_and_max(numbers):
    return min(numbers), max(numbers)


smallest, largest = min_and_max([3, 14, 15, 9, 26])
print(smallest, largest)  # 3 26
```

Встроенные функции `min()` и `max()` возвращают наименьший и наибольший элемент
коллекции.

## Как оформлять функции

Короткие правила, которые пригодятся сразу (подробно про стиль кода — на семинаре 11):

- **Имя — глагол или действие** в `snake_case`: `calculate_total()`, `is_even()`,
  `print_student()`. По имени должно быть понятно, что функция делает
- **Одна функция — одна задача.** Если в названии появляется «и»
  (`load_and_print_data`), функцию стоит разделить
- **Докстринг** в одну строку для всего, что не очевидно из имени
- **Две пустые строки** между функциями на верхнем уровне модуля — так принято в Python
- **Функция либо возвращает значение, либо печатает его.** Смешивать не стоит:
  функцию с `return` проще переиспользовать и проверять

## Темы лекции, которые мы не разбираем на занятии

### Работа с файлами

Файлы (`open()`, режимы доступа, `read()`/`readline()`/`readlines()`/`write()`,
конструкция `with ... as`) подробно разберём на **семинаре 5**. 

### *args и **kwargs

Если число аргументов заранее неизвестно, их собирают в кортеж или словарь:

```python
def sum_all(*numbers):  # все позиционные аргументы попадут в кортеж
    return sum(numbers)


sum_all(1, 2, 3)  # 6
```

Две звёздочки (`**kwargs`) так же собирают именованные аргументы в словарь.
Обратная операция — распаковка готового списка в аргументы: `sum_all(*values)`.

### Функции как объекты и лямбды

Функцию можно присвоить переменной и передать в другую функцию аргументом.
Для коротких функций «на один раз» есть `lambda`:

```python
words = ["питон", "код", "программирование"]
sorted(words, key=lambda word: len(word))  # сортировка по длине слова
```

Встроенные `filter()` и `map()` применяют функцию к коллекции, но то же самое обычно
короче записывается списочным выражением с семинара 3.

> Примеры по этим темам: [`examples/04_args_kwargs_lambda.py`](examples/04_args_kwargs_lambda.py),
> задачи: [«Для самостоятельной работы»](exercises/functions_practice.md#для-самостоятельной-работы).
