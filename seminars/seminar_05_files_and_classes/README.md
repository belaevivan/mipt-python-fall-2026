## Блок 1: Работа с файлами (10 мин)

### Зачем нужны файлы

Все переменные исчезают, когда программа завершается. Чтобы данные пережили запуск —
сохранить настройки, записать результаты, прочитать подготовленный список — их
записывают в файл.

### open() и with

Файл нужно открыть, поработать с ним и обязательно закрыть: пока файл не закрыт,
записанные данные могут не попасть на диск. Чтобы не следить за этим вручную,
используют конструкцию `with`:

```python
with open("data/cities.txt", encoding="utf-8") as file:
    content = file.read()

# здесь файл уже закрыт — автоматически, даже если внутри случилась ошибка
```

`encoding="utf-8"` указывают всегда: без него русский текст на Windows может
прочитаться неправильно.

### Режимы открытия

| Режим | Что делает |
|-------|------------|
| `"r"` | чтение; режим по умолчанию, поэтому его обычно не пишут |
| `"w"` | запись: файл создаётся, а существующий **очищается** |
| `"a"` | дозапись в конец файла |

### Три способа прочитать файл

```python
with open("data/cities.txt", encoding="utf-8") as file:
    text = file.read()  # всё содержимое одной строкой

with open("data/cities.txt", encoding="utf-8") as file:
    lines = file.readlines()  # список строк

with open("data/cities.txt", encoding="utf-8") as file:
    for line in file:  # по одной строке за раз — самый частый способ
        print(line.strip())
```

> **Про `strip()`:** в конце каждой прочитанной строки остаётся символ переноса `\n`.
> Метод `strip()` убирает его вместе с лишними пробелами по краям.

Строку с данными разбирают знакомым `split()` (семинар 3):

```python
name, price = line.strip().split(";")  # "кофе;180" -> "кофе", "180"
```

### Запись в файл

```python
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Отчёт\n")
    file.write(f"Всего строк: {count}\n")
```

Две особенности `write()`: он **не добавляет** перенос строки (его пишут сами)
и принимает **только строки** — число нужно превратить в строку через `str()`
или f-строку.

### Если файла нет

```
FileNotFoundError: [Errno 2] No such file or directory: 'data/cities.txt'
```

Чаще всего причина не в файле, а в том, **откуда запущена программа**: относительный
путь отсчитывается от текущей папки терминала. Как перехватывать такие ошибки, чтобы
программа не падала, разберём на семинаре 8.

> **Подробнее:** см. файл [`examples/01_files.py`](examples/01_files.py)

## Блок 2: Классы и объекты (10 мин)

### Зачем нужны классы

Опишем книгу тем, что уже умеем, — словарём и функцией:

```python
book = {"title": "Евгений Онегин", "author": "Пушкин", "year": 1833}


def describe_book(data):
    return f"{data['title']} — {data['author']}, {data['year']}"
```

Работает, но: ничто не мешает создать словарь без ключа `year` или с опечаткой
в названии ключа, функция живёт отдельно от данных, а когда таких сущностей десятки,
в коде уже не видно, что к чему относится.

**Класс** объединяет данные и действия над ними в одно целое — описание сущности.

| Понятие | Что это | Пример |
|---------|---------|--------|
| Класс | описание, «чертёж» сущности | `Book` |
| Объект (экземпляр) | конкретный представитель класса | книга «Евгений Онегин» |
| Атрибут | данные объекта | `title`, `author`, `year` |
| Метод | действие объекта | `describe()` |

Классов в программе немного, а объектов по ним можно создать сколько угодно.

### Описание класса

```python
class Book:
    """Книга в библиотеке."""

    def __init__(self, title, author, year):
        self.title = title
        self.author = author
        self.year = year


first = Book("Евгений Онегин", "Пушкин", 1833)
second = Book("Мастер и Маргарита", "Булгаков", 1967)

print(first.title)  # обращение к атрибуту через точку
```

Имя класса пишут с заглавной буквы в стиле `PascalCase` — так его видно
среди переменных и функций.

### __init__ и self

`__init__` — **конструктор**: метод, который Python вызывает автоматически при создании
объекта. В нём задают начальные атрибуты.

`self` — ссылка на сам создаваемый объект. Он всегда идёт первым параметром, но при
вызове его не передают:

```python
Book("Евгений Онегин", "Пушкин", 1833)  # три аргумента
#                                       # а в __init__ их четыре — вместе с self
```

Строка `self.title = title` означает: «запиши значение параметра `title`
в атрибут `title` этого объекта».

У каждого объекта свои значения атрибутов — объекты независимы:

```python
first.year = 2024
print(first.year, second.year)  # 2024 1967
```

### Объекты — обычные значения

Их можно складывать в списки и перебирать циклом:

```python
library = [first, second]

for book in library:
    print(f"{book.title} ({book.year})")
```

## Блок 3: Методы и состояние объекта (10 мин)

### Метод — функция внутри класса

Метод описывают как обычную функцию, но внутри класса и с параметром `self`
на первом месте. Через `self` метод добирается до атрибутов объекта:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height


first = Rectangle(7, 4)
print(first.area())  # 28 — self подставляется автоматически
```

Остальные аргументы метода идут после `self`, и для них работает всё, что мы знаем
о функциях с семинара 4, — значения по умолчанию и именованные аргументы.

### Состояние объекта

Метод может не только читать атрибуты, но и **изменять** их. Говорят, что объект
хранит состояние и меняет его в ответ на вызовы методов:

```python
class ShoppingCart:
    def __init__(self):
        self.items = []

    def add_item(self, name, price):
        self.items.append((name, price))

    def count(self):
        return len(self.items)


cart = ShoppingCart()
cart.add_item("кофе", 180)
print(cart.count())  # 1
```

> Сравните с семинаром 4: там функция не могла изменить переменную снаружи
> и приходилось возвращать новое значение. Объект хранит данные внутри себя,
> поэтому метод просто обновляет их.

### Инкапсуляция

Если состояние можно менять откуда угодно, легко привести объект в бессмысленное
состояние — например, сделать баланс счёта отрицательным. **Инкапсуляция** — это идея
«данные внутри объекта, снаружи — только методы», а методы следят за корректностью:

```python
class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self._balance = 0  # подчёркивание означает «не трогать снаружи»

    def withdraw(self, amount):
        if amount > self._balance:
            print("Недостаточно средств")
            return
        self._balance -= amount
```

В Python нет настоящих «закрытых» атрибутов: одно подчёркивание в начале имени —
это соглашение между программистами, а не запрет.

## Темы лекции, которые мы не разбираем на занятии

### Полиморфизм

Полиморфизм — возможность работать с разными объектами через один и тот же интерфейс:
если у нескольких классов есть метод с одинаковым именем, вызывающему коду не важно,
объект какого класса ему достался. По-настоящему эта идея раскрывается вместе
с наследованием, поэтому разберём её на **семинаре 6**.

### Объект, который сохраняет себя в файл

Две темы этого семинара естественно соединяются: объект может сам записывать свои
данные на диск и загружать их обратно. Пример — класс `TodoList`
в файле [`examples/04_class_and_file.py`](examples/04_class_and_file.py), задача —
в разделе [«Для самостоятельной работы»](exercises/files_and_classes_practice.md#для-самостоятельной-работы).
